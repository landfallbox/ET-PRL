\section*{Highlights}

\begin{itemize}
\item ET-PRL frames HVAC action triggering as online anomaly detection.
\item Multi-scale anomaly scores and local-global thresholds enable dynamic event gating.
\item Predictive RL couples with event triggering to reduce redundant control updates.
\item Real data show 53.54\% fewer updates and 2.13\% less energy than fixed-step RL.
\end{itemize}
