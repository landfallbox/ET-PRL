## 一、外层自迭代环总体骨架

内层沿用前一篇 ET-PRL 结构：事件触发预测型 DQN，由控制策略 π 与触发机制共同决定"何时更新冷冻水供水温度设定点"。

外层套一个自迭代环，每轮四步：

1. 部署：用当前 π 与触发机制控制冷站，收集在线运行经验。
2. 迭代触发判断：依据在线经验判断是否启动一次更新，避免固定周期盲目重训。
3. 更新：用部分或选择性方式更新 π 与触发机制，不全量重训，防止遗忘与漂移。
4. 再部署：更新后的 π 与触发机制放回控制回路。

核心差异：触发机制不再是离线标定的统计跟踪，而是作为回路的一部分随控制效果反馈共同进化。

## 二、触发机制设计：三个选项

### 2.1 先分清触发由谁决定

触发由谁决定有两种架构。一是单独门控：触发由独立于控制策略的门控判断，控制策略只负责触发后更新成什么设定点。二是 agent 自己决定：不设单独门控，把"是否更新"并入控制策略的动作空间，agent 每步自己决定更新成某设定点或保持当前值，触发就是 agent 选不选保持。

选项 1、2 属单独门控，选项 3 属 agent 自己决定。

### 2.2 单独门控内部再拆两半

单独门控的判定为 偏离信号 dev(s_t) 与 判定边界 τ 的比较：dev 衡量"当前状态偏离正常或预期多少"，是触发的输入；τ 决定"偏离多少才值得触发"，是触发的决策。

前一篇两半都是统计的：dev 用多尺度流式隔离深度异常分数，τ 用局部-全局双层统计跟踪，含分位数、绝对中位差、快慢时间尺度平滑，灵敏度系数、融合权重、更新率、窗口长度等参数离线标定。

第二篇要学的是 τ 这一半，即判定边界依据控制效果反馈进化；dev 只是"什么变了"的信号，不要求它学习，因此可保留甚至简化。

### 2.3 三个设计选项

| 选项 | 触发由谁决定 | 偏离信号 dev | 判定边界 τ | 特点 |
|---|---|---|---|---|
| 选项 1 | 单独门控 | 简化偏离量，如关键指标对移动基线的偏差 | 可学习标量，自迭代环每轮调一个数 | 最简单、最易归因，"阈值在变"一眼可见 |
| 选项 2 | 单独门控 | 异常分数，沿用前一篇或简化版 | 可学习触发策略 g(s_t)，状态相关 | 表达力强，不同工况不同灵敏度，与 Adaptive ETRL 同路 |
| 选项 3 | agent 自己决定 | 不单独计算 | 无独立 τ，触发并入动作空间 | 最 RL 原生，但不再有显式 τ，"阈值共同进化"表述需改写 |

选项 3 有一个值得记录的变体：不并入动作空间，而是设独立学习门控，一个以当前状态为输入、输出是否触发的神经网络，同时替代 dev 与 τ。该变体表达力更强，但同样没有显式 τ，贡献表述与选项 3 面临同样的改写问题，且失去 dev 的物理锚点后触发依据最隐晦，存在恒触发、恒不触发或靠少触发刷低控制代价的退化风险。其价值在于作对照组：实验中加入一组全学习触发，若保留 dev 与 τ 的版本胜出，直接得到回答"为什么保留 dev"的消融；若性能相当，主方法可简化为该变体。

### 2.4 各选项取舍

选项 1 故事最干净、旋钮最少，"阈值共同进化"最容易可视化，也最容易与前一篇、规则式阈值做对照，适合做基线。

选项 2 在选项 1 基础上把标量阈值升级为状态相关的触发策略，能表达"不同工况用不同灵敏度"，是选项 1 的自然扩展，适合作为消融或增强。

选项 3 把偏离信号也并入学习策略，触发完全由 agent 内生决定，最彻底但偏离"事件触发"的物理解释，且触发依据最隐晦，适合作为远期形态提一句，不作主实验。

### 2.5 必须守住的风险

无论选哪个，dev 信号不能砍没。事件触发要站住，得有"什么变了"的有意义信号；哪怕 τ 是学的，dev 也得是反映工况偏离的量，否则审稿人会问触发的依据是什么。简化的对象是判定边界与信号复杂度，不是把触发变成无依据的任意门。

### 2.6 倾向

基线用选项 1，选项 2 作扩展或消融，选项 3 远期提及。最终留会上定。

### 2.7 Adaptive ETRL 精读笔记与架构决策记录

> 日期：2026-10-05。基于 arXiv 2409.19769 本地 PDF 精读。

**机制提炼。** Adaptive ETRL，即 ATPPO，针对带界扰动的连续时间非线性系统联合学习控制策略与触发条件，由四个机制组成：

1. 状态增广。输入不是裸状态，而是状态拼接累积奖励 r_acc，使触发决策能参考整段轨迹至今的性能，这是其自适应与非平稳性的来源。
2. 联合输出。策略网络同时输出触发信号 Φ 与控制 u，Φ 非负则触发，否则零阶保持上一次控制；判定边界固定为 0，学的是整个 Φ 函数；控制每步都计算，仅在触发时应用。
3. 触发惩罚。目标函数含每次触发的惩罚项，用固定超参控制触发频率与控制性能的平衡。
4. 防 Zeno。保证事件间时间间隔有正下界，不发生连续触发。

实验全部为仿真：受扰单积分器、MuJoCo 运动、目标拦截；对比 PPO 省 80% 以上通信且性能不降。

**与本文的三点差异。**

| 维度 | Adaptive ETRL | 本文 |
|---|---|---|
| 学习时机 | 离线一次训练，部署后 Φ 冻结 | 外层自迭代环，τ 随在线经验持续进化 |
| 阈值 | 无显式 τ，边界固定 0 | 显式 τ，阈值变化可画曲线、可归因 |
| 场景 | 纯仿真，无非平稳真实工况 | 真实冷站数据，工况漂移是动机本身 |

**可借鉴的三个机制。**

| 机制 | 用在哪 |
|---|---|
| r_acc 状态增广 | 喂给门控输入，使触发决策带轨迹历史记忆 |
| 触发惩罚项 | 内层 DQN 训练的稳定器 |
| 事件间时间正下界 | τ 更新后的安全护栏，防 τ 学崩导致连续触发 |

**决策一：触发惩罚不作主机制。** 触发惩罚项回答"好的触发频率是多少"，是训练期的静态问题；可学习 τ 回答"工况漂移时触发灵敏度该怎么变"，是部署期的动态问题。本文动机即非平稳，固定惩罚权重追不上工况漂移，且权重本身是专家设定的静态参数，会复现第一篇所批评的问题。故主机制为门控加可学习 τ，触发惩罚降格为训练辅助与消融对照。

**决策二：不换底座为 ATPPO 式联合策略。** 曾考虑在联合策略上加 RSI 环而非在 ET-PRL 上加，不采纳，理由有三：

1. 违反与第一篇延续的硬约束：换底座后 ET-PRL 不再是被继承的基础，系列叙事断裂。
2. 新颖性被稀释：在线更新的 RL 控制不是空白，清华 2026 自进化数字孪生、continual RL for HVAC 2025、SELFI 均占此区域；"显式触发阈值随闭环经验共同进化"才是已确认的空白。换底座等于从空白区退回拥挤区。
3. 更新成本与风险更高：联合方案每轮需微调整个策略网络，遗忘、漂移与触发行为退化都藏在权重里，无护栏可查；τ 路线每轮只更新一个显式对象，可限幅、可画曲线、可归因。

联合策略进对照组：漂移工况下若追不上 τ 进化路线，直接支撑"部署期可进化性比训练期联合优化更值钱"这一核心论点。

## 三、其余设计问题：待线 A 精读后补

以下四问对应 5.1 第 2 步，需精读线 A 七篇与 2.9 第一梯队五篇后给暂定答案与依据：

1. 外层环何时触发一次迭代：固定周期、性能退化检测、还是经验累积量？
2. 每次迭代怎么更新：部分重训、选择性重训、还是增量微调？如何避免全量重训的遗忘。
3. 怎么防遗忘与防漂移：KL 正则、经验回放、还是策略锚定？
4. 跨轮信用分配：哪轮在线经验归因给哪次更新，如何避免把环境漂移误判为策略失效。

## 四、与前一篇的延续与差异小结

延续：事件触发预测型 RL 结构、非平稳冷站问题、按需更新降低控制代价。
差异：触发机制从统计自适应升级为学习式可进化，控制策略从离线一次训练升级为闭环自迭代，二者共同更新。

## 五、方向备选：RSI 与冷站控制的其他结合点

RSI 的本质是系统改进自身的某个组成部分。一个强化学习 agent 由多个环节组成，当前方向占了决策策略与触发阈值两个环节，其余环节都可作为自迭代对象，构成备选方向。

| 自迭代环节 | 方向 | 状态 | 与第一篇衔接 | 新颖性 | 主要风险 |
|---|---|---|---|---|---|
| 决策策略 π | 策略自迭代 | 已占 | 强 | 中 | 灾难性遗忘 |
| 触发阈值 τ | 阈值自迭代 | 已占 | 强 | 中高 | 触发器漂移 |
| 认知，世界模型 | 环境模型自迭代 | 备选 | 最强 | 高 | 模型学偏误导策略 |
| 目标，奖励 | 奖励与多目标权重自迭代 | 备选 | 中 | 中高 | 奖励钻空子 |
| 学习过程 | 超参数与探索率自迭代 | 备选 | 中 | 中 | 元层不稳定 |
| 感知，状态表示 | 特征与表示自迭代 | 备选 | 弱 | 中 | 表示漂移致策略失效 |
| 行动，动作空间 | 可调变量与调节粒度自迭代 | 备选 | 弱 | 高 | 动作空间变化致策略失效 |

### 5.1 世界模型自迭代，认知层

RSI 改进的是 agent 对冷站动力学的认知。冷站有热惯性，冷冻水温度、蓄冷、负荷响应使动力学随季节与负荷漂移。让 agent 维护一个预测模型，给定当前设定点与负荷预测下一时刻关键指标，随预测误差自迭代。

为什么最值得：第一篇 ET-PRL 本身是预测型 DQN，这个方向从预测型自然长出，把预测从固定模块升级为会自我修正的认知，衔接最顺。RSI 纯度也高，agent 依据预测误差修正对环境的理解，理解更准又带来更好的预测，正反馈清晰。风险是模型学偏会误导策略，需要模型置信度门控，模型不确定时回退保守策略。

### 5.2 奖励与多目标权重自迭代，目标层

RSI 改进的是 agent 自己的目标。冷站是多目标，能耗、舒适度、设备寿命、能效比，奖励通常是这些的加权和。让权重随运行经验自迭代，夏季高峰重舒适度，过渡季重能耗。

为什么值得：故事清晰，agent 学会在不同工况下重新权衡能耗与舒适，非平稳适应的动机天然成立。RSI 纯度高但风险最典型，奖励自迭代极易奖励钻空子，比如牺牲舒适度换低能耗读数，必须加约束与安全边界。与当前方向正交，当前是策略与阈值怎么进化，这个是进化朝哪个目标，两者可组合。

### 5.3 判断与系列化设想

当前方向，策略与阈值自迭代，仍是主线，与第一篇衔接最紧、故事最聚焦，适合作第二篇。世界模型自迭代是最强的备选与第三篇候选，从预测型长出，且与当前方向不冲突，甚至可组合成自迭代策略加自迭代世界模型。奖励自迭代故事最吸引人但风险最高，适合作扩展实验或单独一篇，前提是能管住奖励钻空子。

会上可抛给老师的点：第二篇做策略与阈值自迭代，第三篇做世界模型自迭代，两篇共享同一套冷站平台与事件触发框架，形成系列，比单篇更有说服力，也给老师一个这条线能走多远的图景。
