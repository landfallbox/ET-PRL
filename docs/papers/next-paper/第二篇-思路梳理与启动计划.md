# 第二篇思路梳理与启动计划

> 用途：从原始想法出发，完整梳理第二篇的思路链条与当前进展，明确第一步工作与并行准备事项。
> 配套：`第二篇-定位陈述.md`、`第二篇-方法设计骨架.md`、`文献调研-自迭代RL冷站控制.md`。
> 日期：2026-10-05。
> 状态：思路链条已闭合；Phase 0 动机验证未启动。

## 一、思路链条

从"RSI 能否与 HVAC 结合"到第二篇定位，完整逻辑链共七步。

1. 原始想法。RSI，即 Recursive Self-Improvement，自迭代，指系统改进自身的某个组成部分；问题是该机制能否落到 HVAC 控制上。
2. 约束。第二篇必须延续第一篇 ET-PRL 的工作，不能完全无关。
3. 第一篇做了什么。ET-PRL 是事件触发预测型 DQN：预测型 DQN 策略 π 输出冷冻水供水温度设定点，门控模块由流式隔离深度异常分数与局部-全局双层统计自适应阈值 τ 组成，决定何时更新设定点。实验上，与固定步长基线相比动作更新次数降低 53.54%，日均能耗由 7491 降至 7332 kWh/day，性能保持率 94.41%。
4. 第一篇的遗留空白。π 离线训练一次后冻结，部署后不随工况漂移更新；τ 只对异常分数分布做统计跟踪，机制参数离线标定，不依据控制效果反馈学习。两个组件都是一次性的，恰好构成 RSI 最自然的两个自迭代对象。
5. RSI 落点。在 ET-PRL 外再套一个外层自迭代环，每轮依次执行部署、收集在线经验、迭代触发判断、更新 π 与 τ、再部署，使控制策略与触发机制随闭环经验共同进化。
6. 文献验证。应用侧冷站与建筑 RL 工作均为静态策略，非平稳工况靠多策略档案、变化点检测加模型切换、退化触发再学习或数字孪生重训应对，没有闭环自迭代；方法侧自改进 RL 集中在 LLM、机器人与蛋白设计域，没有建筑能源控制。闭环自迭代与策略、触发阈值共同进化的交叉点为空白，定位成立，详见文献调研第五节。
7. 系列化视角。第二篇做策略与阈值自迭代，为主线，与第一篇衔接最紧；第三篇候选做世界模型自迭代，从第一篇的预测型结构自然长出。两篇共享同一冷站平台与事件触发框架，形成系列。

## 二、分步执行计划

> 以下为从零开始的干净计划，独立于当前进展。核心原则三条：动机先于方法，先证明问题存在再设计方法；最便宜的验证先做，复用现有资产，不新增依赖；先定实验再写代码，基线与消融组在实现前定死。

| 步骤 | 做什么 | 产出 / 退出标准 |
|---|---|---|
| 1. 写研究问题 | 三个动作：把想法写成能回答是或否的问题，例如"第一篇的静态策略在非平稳工况下是否退化，策略与触发阈值的闭环自迭代能否恢复性能"；把 agent 拆成策略、触发阈值、奖励、世界模型、超参数、状态表示、动作空间等组件，按与第一篇衔接度、动机强度、可行性三条标准挑出自迭代对象；把结论浓缩成一页定位陈述 | 一页定位陈述：一句话讲清做什么、与前一篇什么关系、解决什么问题 |
| 2. 定向文献调研 | 只回答三个问题：交叉点是否空白、最近邻是谁、如何划界、有哪些机制可借鉴；机制论文按"拆环怎么转"读，不为读而读 | 空白点陈述加最近邻差异表加机制笔记，与步骤 3 并行 |
| 3. Phase 0 动机验证 | 全程唯一的通过与否闸门：用最便宜的可用平台跑静态策略，回答两个问题：性能是否随时间与工况退化、触发是否失配 | 一条退化曲线加明确结论；不成立则停手或换故事，不进入后续步骤 |
| 4. 方法设计 | 回答设计四问：外层环何时迭代、每次怎么更新、如何防遗忘、跨轮信用分配；触发从最简形式即可学习标量阈值起步，状态相关形式作扩展；同时定死基线与消融清单 | 方法骨架加实验方案，含对比方法与消融组 |
| 5. 数据与平台决策 | 由 Phase 0 结果收敛：旧数据是否足够支撑退化叙事，不够则新数据清洗升为关键路径；定主实验平台：仿真器还是真实数据滚动回放 | 平台决策加数据就绪 |
| 6. 实现 | 内层完整复用第一篇，只新建外层：在线经验收集、迭代触发判断、带锚定正则的部分式更新、阈值更新；先跑通最简选项的端到端，再加扩展 | 端到端可运行的自迭代管线 |
| 7. 实验 | 主对比：自迭代 vs 静态策略 vs 离线重训 vs 多策略档案与变化点切换 vs 规则式自适应阈值；消融：去掉阈值更新、去掉锚定正则、全量重训、固定周期迭代 | 主结果表加消融表加敏感性分析 |
| 8. 写作投稿 | 动机曲线放第一张图，贡献表述与定位陈述对齐 | 投稿稿 |

排序上的三个关键点：

1. 步骤 3 是唯一的硬闸门，其余步骤可并行或调整。文献调研与方法骨架可在 Phase 0 运行期间推进，但方法实现必须等闸门通过，否则可能花数周实现一个动机不存在的方案。
2. 步骤 4 里"先定基线"容易被跳过但最值钱。基线定了才知道要收集哪些数据、留哪些对照，实验是设计出来的，不是临时凑的。
3. 步骤 5 放在 Phase 0 之后而不是之前，因为平台选型的答案取决于旧数据上退化是否足够明显：先跑探针再选平台，避免数据清洗投入方向押错。

## 三、Phase 0 动机验证：执行细则

> 对应第二节步骤 3。步骤 1 已完成，步骤 2 的调研、机制笔记与设计决策已就位，剩余精读与跨轮信用分配可与 Phase 0 并行补。Phase 0 是当前第一个要执行的步骤，以下为执行细则。

### 3.1 为什么排第一

整篇论文的动机建立在单一前提上：静态策略在非平稳工况下确实退化，且退化程度足以支撑闭环自迭代的必要性。前提不成立，外层环设计再好动机也不成立。该问题同时是待拍板开放问题的第一条，先有数据再讨论，讨论才有抓手。

### 3.2 执行路径

复用第一篇平台，仓库内代码齐备，无新增依赖：

1. 使用第一篇的上海商业建筑数据、已校准 EnergyPlus 模型与现有 ET-PRL 代码，训练或加载静态策略 π₀，τ 保持统计自适应。
2. 在测试集或更长的数据段上按时间滚动评估，绘制性能随时间与工况变化的曲线。
3. 同步观察触发侧：τ 是否失配，误触发与漏触发是否随时间增多，以支撑"阈值也需要进化"的半边论据。

### 3.3 产出标准

一条粗糙的退化曲线，加一个明确结论：成立、不成立、或数据还差哪一步。

### 3.4 风险提示与边界

第一篇数据仅 102 天，测试集约 15 天，时间跨度可能不足以表现出显著退化。若探不出退化，该结论本身有价值：说明正式实验必须使用新竞赛数据，数据清洗优先级随之上升。

Phase 0 只回答"是否退化"，不回答"怎么修"，不进入方法实现细节。

## 四、并行准备

> 对应第二节步骤 2 与步骤 5，以下为执行要点。

1. 线 A 精读剩余七篇。12 篇已下载；RLoop、高效重启、SELFI、ProteinZero、Adaptive ETRL 五篇已有机制拆解（见文献调研 2.7.1 与方法骨架 2.7），剩余七篇：Tri-CRLAD 与 CQD-ERL 补回路内调阈值、多策略档案与安全盾两根机制线；AEL、CPE、Skill-R1、EvolveR、COSPLAY 分别对应外层触发判据、防遗忘度量、跨轮信用分配、环结构印证、π 与 τ 共同进化。最高优先是 Skill-R1：跨轮信用分配是设计四问中唯一还没有暂定答案的一问。读法与每篇对应的设计问题见 `next-paper-reading/清单.md`，产出回落文献调研 2.7.1 与 2.9、方法骨架第三节四问。
2. 数据侧。确认新竞赛数据的权限、目标项目与清洗工作量，为平台选型提供依据。

## 五、节奏与待拍板事项

节奏分三段：

1. 本周：Phase 0 快速探针，用第一篇平台，目标一周内出退化曲线；同步完成线 A 前三篇精读。
2. 出结果后：拿动机结论与设计四问暂定答案与老师讨论，拍板四个开放问题：动机强度、π 与 τ 先做哪个、平台、基线。
3. 拍板后：进入方法实现，外层环加触发机制选项 1。

一句话总结：思路链条已闭合，从 RSI 到第一篇 π 与 τ 的遗留空白，再到外层自迭代环与文献空白验证；当前缺的不是想法，而是静态策略退化的证据曲线，它决定这篇论文做不做、怎么做。下一步即执行该验证。
