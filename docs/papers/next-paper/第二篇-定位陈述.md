# 第二篇论文定位陈述

> 用途：找老师讨论第二篇做什么、怎么做。一页 A4，30 秒可读完。
> 配套：`文献调研-自迭代RL冷站控制.md` 的第三、四、五节；方法设计见 `第二篇-方法设计骨架.md`。
> 日期：2026-09-28。

## 一句话定位

在真实冷站群控数据上，把前一篇 ET-PRL 的"事件触发 + 预测型 DQN"结构，从离线训练一次、部署后控制策略不再更新，升级为**闭环自迭代**：控制策略与触发机制随在线运行经验共同更新，解决非平稳工况下的性能退化。

## 与前一篇的关系

ET-PRL 训练完成后，控制策略固定，不再依据在线经验更新；触发阈值虽在测试时随异常分数分布在线自适应，但只是对分数分布的统计跟踪，不学习触发策略、不依据控制效果反馈进化，其机制参数也是离线标定的。

第二篇要补的就是这一环：在 ET-PRL 之外套一个外层自迭代环，让控制策略与触发机制随在线运行经验共同更新，按"部署、收集在线经验、迭代触发判断、更新策略与触发机制、再部署"循环，使系统随工况漂移持续适应。

## 要解决的问题

冷站运行工况随季节、负荷、设备老化持续漂移，属于非平稳环境。现有冷站 RL 工作几乎都是静态策略，离线训练一次后部署，非平稳靠多策略档案、变化点检测加多模型切换、迁移学习或数字孪生重训来应对，没有闭环自迭代。ET-PRL 的触发阈值虽自适应于异常分数分布，但阈值机制本身也是离线标定的，不随闭环经验进化。所提方法要同时解决两件事：控制策略随工况退化，以及触发阈值随工况失配。

## 核心思路

外层自迭代环，每轮做四件事：

1. 部署：用当前策略与阈值控制冷站，收集在线运行经验。
2. 触发判断：依据在线经验判断是否需要启动一次迭代更新，避免固定周期盲目重训。
3. 更新：用部分或选择性方式更新策略与触发阈值，不全量重训，防止遗忘历史与策略漂移。
4. 再部署：把更新后的策略与阈值放回控制回路。

策略与触发的共同进化是核心差异：触发机制从"只跟踪分数分布的统计自适应"升级为"依据控制效果反馈学习的可进化策略"，与控制策略作为回路的一部分共同更新。

触发机制具体怎么做，先分清一个关键问题：触发由谁决定。有两种架构。

一是单独门控：触发由独立于控制策略的门控判断，控制策略只负责"触发后更新成什么设定点"。门控内部由偏离信号 dev 与判定边界 τ 组成，dev 衡量"什么变了"，τ 决定"偏离多少才值得触发"，第二篇要学的是 τ 这一半，dev 可保留甚至简化。

二是 agent 自己决定：不设单独门控，把"是否更新"并入控制策略的动作空间，agent 每步自己决定"更新成某设定点"或"保持当前值"，触发就是 agent 选不选保持。

| 选项 | 触发由谁决定 | 偏离信号 dev | 判定边界 τ | 特点 |
|---|---|---|---|---|
| 选项 1 | 单独门控 | 简化偏离量，如关键指标对移动基线的偏差 | 可学习标量，自迭代环每轮调一个数 | 最简单、最易归因，"阈值在变"一眼可见 |
| 选项 2 | 单独门控 | 异常分数，沿用前一篇或简化版 | 可学习触发策略 g(s_t)，状态相关 | 表达力强，不同工况不同灵敏度，与 Adaptive ETRL 同路 |
| 选项 3 | agent 自己决定 | 不单独计算 | 无独立 τ，触发并入动作空间 | 最 RL 原生，但不再有显式 τ，"阈值共同进化"表述需改写 |

注意：选项 1、2 有显式 τ，与"策略与触发阈值共同进化"的定位一致；选项 3 把触发吸收进策略，没有独立 τ，贡献表述要改成"自迭代 agent 学习何时行动"。

倾向：选项 1 作基线，选项 2 作扩展或消融，选项 3 作为不同表述的远期形态。留会上定。

## 与最近邻的差异

| 最近邻 | 它做了什么 | 与所提方法的差异 |
|---|---|---|
| Energies 2025 再学习框架 | 性能退化时触发再训练 | 是退化触发重训，非经验闭环自迭代，且不更新触发阈值 |
| BAE 2022 变化点检测加多模型切换 | 检测工况变化后切换预训练模型 | 是离散多模型切换，非单策略连续自迭代，阈值不随工况平滑变化 |
| Applied Energy 2025 自适应冷机切换阈值 | 物理引导加故障诊断的规则式阈值 | 阈值靠物理规则与故障先验，非 RL 回路内生学习 |
| Adaptive ETRL，arXiv 2024 | 联合学习控制策略与触发条件，触发隐式无显式阈值 | 离线一次训练，部署后触发行为冻结，不随在线经验自迭代；精读与划界见方法骨架 2.7 节 |

## 贡献表述

首个在真实冷站群控数据上验证的自迭代方法，通过闭环经验迭代同时适应控制策略与事件触发阈值，解决控制策略在非平稳工况下的退化，以及触发阈值仅做统计跟踪、不随控制效果反馈进化的局限。

## 待拍板的开放问题

1. 动机强度：冷站数据上静态策略的退化是否足够强，值不值得做闭环自迭代？
2. 兜底：若触发机制共同进化被证明不可行，是否接受降级为只做策略自迭代的最小版本，τ 保持 ET-PRL 的统计自适应？
3. 平台：闭环自迭代要求环境能对 agent 自身动作给出反馈，纯真实数据回放无法闭环，主平台必须是真实数据驱动的校准仿真器。待拍板的是用哪个仿真器、保真度是否足够。
4. 基线：对比离线重训、多策略档案、变化点检测加多模型切换、联合事件触发策略中的哪些？
