\section*{Highlights}

\begin{itemize}
\item ET-PRL reformulates HVAC action triggering as online anomaly detection.
\item Multi-scale anomaly scoring with local-global thresholds enables dynamic event gating.
\item Predictive RL is coupled with event triggering to reduce redundant control updates.
\item Real chiller data show ET-PRL outperforms fixed-step RL, with 53.54\% fewer updates and 2.13\% lower energy consumption.
\end{itemize}
