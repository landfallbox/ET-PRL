# JOBE 投稿检查清单

更新时间：2026-07-20

依据：Journal of Building Engineering Guide for Authors。

## 已完成

- [x] 使用独立目录保留原 Applied Energy 投稿版本。
- [x] 将标题、摘要、关键词、引言贡献和结论改为建筑 HVAC 工程定位。
- [x] 明确研究基于实测运行数据驱动的校准 EnergyPlus 仿真，不表述为现场闭环实验。
- [x] 区分策略网络执行次数和实际设定值变化次数，并与实验实现统一。
- [x] 删除与建筑 HVAC 论述不匹配的参考文献和错误校准引用。
- [x] 摘要不超过 250 词，关键词不超过 7 个。
- [x] 准备 5 条 Highlights，每条不超过 85 个字符。
- [x] 保留 CRediT、利益冲突、基金、数据可用性和生成式 AI 声明。
- [x] 准备 JOBE 定制 cover letter。

## 投稿前阻断项

- [ ] 将研究数据和代码归档到 Zenodo、Mendeley Data 或机构数据仓库并获得 DOI。
  - JOBE 执行 Research Data Option C：应存入相关数据仓库并在文章中引用和链接；无法共享时必须说明原因。
  - 当前 GitHub 地址可用于代码协作，但不应替代带版本和 DOI 的长期归档。
  - 获得 DOI 后更新主稿 `Data availability`，并按数据集引用格式加入参考文献。

- [ ] 由全体作者核对新标题、作者顺序、单位、CRediT 和共同通信作者设置。
- [ ] 确认从 Applied Energy 撤稿或拒稿流程已结束，稿件当前未在其他期刊审理。
- [ ] 在线提交时填写通信作者完整邮寄地址、电话和最新邮箱。

## 建议项

- [ ] 补充 EnergyPlus 模型校准方法、校准期和误差指标。当前正文只说明使用实测数据校准，JOBE 审稿人可能要求可复现的校准证据。
- [ ] 补充计算环境和单次 policy inference 时间，以支撑在线部署效率讨论。
- [ ] 视投稿系统提示准备 graphical abstract。JOBE 鼓励但不强制，要求至少 531 x 1328 pixels，或同比例更高分辨率。
- [ ] 人工核对所有参考文献的作者、题名、卷期、页码或文章号和 DOI。
- [ ] 在 Editorial Manager 中逐张上传图件，并检查缩放后的文字可读性。
