# 期刊投稿选择（ET-PRL 论文）

> 论文：《基于动态事件触发的 HVAC 强化学习预测控制方法》（ET-PRL）
> 方法核心：事件触发 + 预测式强化学习（DQN）+ LSTM 负荷预测，用于商业建筑冷冻水供水温度控制
> 实验：102 天上海真实建筑数据 + 校准 EnergyPlus 模型；6 组对比 + 5 组消融 + 5 参数敏感性；代码已开源

## 一、论文质量定位

- **优点**：贡献清晰、实验设计完整（对比 + 消融 + 敏感性）、真实数据 + 仿真验证、代码开源、中英双稿就绪。
- **短板**：节能幅度偏保守（2.13%）、单建筑单冷机、DQN 为基础 RL 算法、验证以仿真为主。
- **结论**：整体为"扎实但偏增量"的工作，**目标锁定中科院三区及以下**（二区及以上不再考虑）。

## 五、投稿注意事项

1. **分区动态**：中科院分区每年调整，且存在"基础版 / 新锐版"差异。投稿前用当年官方《中科院期刊分区表》或 LetPub 核对目标刊最新分区。
   - 表中 IF / 分区取自 LetPub 2026 年 6 月最新影响因子数据更新（2025 JCR 单值，非区间均值）；LetPub"审稿周期（体感）"为作者投稿口径（含 desk reject 与重审），比官网"录用天数"宽，两者不可直接对比。
2. **非 OA 操作**：混合刊投稿时选择 **Subscription / 非开放获取** 出版模式即可，无需支付 APC。
3. **速度数据口径**：表中"首决 / 录用"天数取自各出版社官网（Elsevier 为 ScienceDirect 期刊页"Submission to first decision / acceptance"，Springer 为期刊页"Submission to first decision"），检索日期 2026-09-01，第三方估计仅作次要参考。
   - IJR 官网未单独公布首决周期；Springer 期刊普遍只公布首决、不公布录用周期。
   - 首决天数偏短主要反映编辑初审（desk decision）速度，真正衡量审稿快慢应重点看**录用天数**。
   - 实际周期以期刊当期负载为准，可在投稿系统查看"平均审稿周期"。
4. **稳妥策略**：优先投 SMPAT / IJR / ETFS 这类"分区达标 + 出版社强 + 非 OA + 速度较快"的三区刊；IJGEE 与 Energy Efficiency 作为备选兜底。
